## 🎯 Mejores Prácticas

### 📝 Diseño de Preguntas

**✅ Hacer:**
- Preguntas claras y específicas
- Usar escalas consistentes (1-5 o 1-10)
- Incluir opción "No aplica" cuando sea necesario
- Limitar a 5-7 preguntas máximo
- Hacer preguntas obligatorias solo cuando sea esencial

**❌ Evitar:**
- Preguntas muy largas o confusas
- Múltiples conceptos en una pregunta
- Opciones de respuesta que se superponen
- Demasiadas preguntas abiertas
- Preguntas que puedan ofender

### 📧 Estrategia de Envío

**Timing:**
- **Post-reserva**: 2-3 días después del checkout
- **Durante la estadía**: Para servicios específicos
- **Eventos**: Inmediatamente después del evento

**Segmentación:**
- Por tipo de cliente (nuevo vs. recurrente)
- Por servicios utilizados
- Por temporada o período
- Por duración de estadía

**Frecuencia:**
- Máximo 1 encuesta por cliente por mes
- Evitar spam de encuestas
- Priorizar encuestas más importantes

### 📊 Análisis de Resultados

**Métricas Clave:**
- **Tasa de respuesta**: % de invitaciones respondidas
- **Satisfacción promedio**: Rating promedio por pregunta
- **Tendencias**: Cambios en el tiempo
- **Comentarios**: Análisis de texto libre

**Acciones Basadas en Resultados:**
- **Ratings bajos**: Investigar causas específicas
- **Comentarios negativos**: Seguimiento personalizado
- **Sugerencias**: Evaluar viabilidad de implementación
- **Tendencias**: Ajustar servicios según feedback

### 🔄 Encuestas Automáticas por Evento

```typescript
// Trigger automático después de checkout
export async function triggerPostCheckoutSurvey(reservationId: number) {
  const reservation = await getReservation(reservationId);
  const client = await getClient(reservation.client_id);
  
  // Crear campaña automática
  const campaign = await createCampaign({
    survey_id: POST_CHECKOUT_SURVEY_ID,
    name: `Post-Checkout ${reservationId}`,
    sender_name: 'Termas Llifén',
    sender_email: 'feedback@termasllifen.cl',
    clientIds: [client.id]
  });
  
  // Enviar después de 2 días
  setTimeout(() => {
    sendSurveyInvitations(campaign.id);
  }, 2 * 24 * 60 * 60 * 1000); // 2 días
}
```

### 📈 Dashboard de Métricas

```sql
-- Vista de métricas por encuesta
CREATE VIEW survey_metrics AS
SELECT 
  s.id,
  s.title,
  COUNT(DISTINCT si.id) as total_invitations,
  COUNT(DISTINCT sr.id) as total_responses,
  ROUND(COUNT(DISTINCT sr.id) * 100.0 / COUNT(DISTINCT si.id), 2) as response_rate,
  AVG(CASE WHEN q.question_type = 'rating' THEN (a.answer_value->>0)::numeric END) as avg_rating
FROM surveys s
LEFT JOIN survey_invitations si ON s.id = si.survey_id
LEFT JOIN survey_responses sr ON si.id = sr.invitation_id
LEFT JOIN survey_questions q ON s.id = q.survey_id
LEFT JOIN survey_answers a ON q.id = a.question_id AND sr.id = a.response_id
GROUP BY s.id, s.title;
```
